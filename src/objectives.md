# Project Objectives

The primary objectives of this project are:

1. Design and implement a continuously operating **web scraper** that collects cryptocurrency data from live feeds.

2. Build a **real-time analytics processor** that transforms raw data into actionable insights

3. Create a **dynamic visualization interface** with **temporal dimensions** for exploring
market trends

4. Apply the **producer-consumer** paradigm throughout the architecture for scalability

5. Deploy the system using modern **containerization** and **orchestration** technologies
